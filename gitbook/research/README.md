# 研究

我以设计探究为方法，关注人机界面如何塑造判断、信任与日常知识实践。

> 示例档案——此处不声明机构归属、发表成果或已完成研究。

## 研究条目

### [人机协作](human-ai-collaboration/README.md)

让机器辅助可检查、可修正，同时保留人的判断能力。

### [信任校准](trust-calibration/README.md)

不确定性、解释与错误修复如何帮助人们恰当地依赖人工智能。

### [思考工具](tools-for-thought/README.md)

支持注意、反思与长期知识积累的数字环境。
