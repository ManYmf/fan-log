## 给 Codex 的要求

保留完整中文正文，整理成 GitBook Markdown，不生成英文版本。保留代码和文献原题，不添加未经提供或核实的个人经历、研究成果或引用信息。

整理标题、摘要、日期、标签和参考文献，维护相关目录与索引，并检查链接、公式、代码和脚注。

按所属板块建立 `gitbook/writing/<文章 slug>/`、`gitbook/research/<条目 slug>/` 或 `gitbook/learning/<笔记 slug>/`，正文统一保存为 `README.md`，有配图时建立 `images/`。在 `gitbook/SUMMARY.md` 的对应板块下添加指向正文的子页面链接，并更新相应总览及站内链接。写作文章直接列在“写作”下。学习记录保留用户提供的课程名称与学习进度。

README 页面主要通过本地 Git 维护。移动页面时同步检查目录、图片引用与来源记录；准备发布时按原有 slug 核对公开页面 URL，确认地址变化后再处理重定向。
