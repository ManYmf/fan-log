# Fan（凡）’s Log 中文文章草稿模板

> 这是“中文单一来源”模板，不会直接成为网页。你只需要填写中文和资料来源；英文翻译、文章元数据、BibTeX、网页格式、检查与发布都交给 Codex。

## 怎么使用

1. 不要直接修改这份母版；复制一份到 `.drafts-private/`，按“文章题目.md”命名。
2. 最少填写中文标题和“中文正文”。摘要及其余项目不确定时可以留空，由 Codex 起草或询问。
3. 正文需要引用资料时写 `【资料1】`、`【资料2】`；需要脚注时写 `【脚注1】`。不必自己写 BibTeX。
4. 写完后把草稿路径交给 Codex，并要求“先预览，不提交、不发布”。
5. 模板中的任何勾选都不代表正式发布授权；只有你在对话中明确确认后，Codex 才能推送和部署。

## 八、事实与隐私自查

- [ ] 人名、机构、职位、论文状态和日期均准确。
- [ ] 数据、事实、直接引语和他人观点已尽量提供来源。
- [ ] 个人推测与已验证事实已经区分。
- [ ] 没有密码、令牌、私人地址、身份证件或保密材料。
- [ ] 图片、长引文和附件拥有公开使用权。
- [ ] 中译英可以公开，但仍需在预览后由我最终确认。

## 九、给 Codex 的处理要求

- 以本文件的中文为唯一内容来源，不自行增加事实、经历、成果或立场。
- 先指出明显的事实缺口、来源不足、歧义和可能涉及隐私的地方。
- 忠实翻译成完整英文；保留含义和语气，但允许为英文可读性调整句序。
- 将 `【资料N】` 转成经过核实的 BibTeX 与 APA 作者—年份引用；不得虚构文献字段。
- 将 `【脚注N】` 转成中英文各自唯一的脚注 ID。
- 生成稳定的 ASCII slug、`meta.yaml`、`en.mdx` 和 `zh.mdx`。
- 估算中英文阅读时长，并只使用合法标签；需要新标签时先说明。
- 运行完整校验和构建，先展示本地预览。
